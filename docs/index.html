You already have Claude Code. pa-pack gives it a job: reading your mail, calendar, Slack and Jira, keeping follow-ups, sending you a morning brief and an update every hour or two, answering on Telegram from your phone, remembering what matters. It lives in one folder you pick, runs in the background from a tray icon, and never touches anything outside the folders you allow.

Download

One file, no installer wizard of the OS kind: run it and a local page opens in your browser. It brings the rest (Claude Code, Bun, Git Bash, tmux) if missing.

Then run it

Windowsdouble-click pa-installer-x86_64-pc-windows-msvc.exe (SmartScreen: More info → Run anyway; it is unsigned)
macOSchmod +x pa-installer-*-apple-darwin && xattr -d com.apple.quarantine pa-installer-*-apple-darwin && ./pa-installer-*-apple-darwin
Linuxchmod +x pa-installer-x86_64-unknown-linux-gnu && ./pa-installer-x86_64-unknown-linux-gnu
The installer serves its wizard on 127.0.0.1 only, with a random token in the URL it prints. Nothing is sent anywhere except the Telegram token to api.telegram.org, if you set one.

What you get

🎭
A personality
Serious, Fun, Weird, Warm, Sarcastic, Zen, Hype, or your own words. It shows in every message, Telegram included. Facts stay exact.
📱
Your phone
A Telegram bot of your own (BotFather, one minute). The installer verifies the token and allowlists you: no pairing codes. Talk to it, get pushes.
📡
Proactive loop
Every 15 min to 4 h on workdays it reads its memory and follow-ups, checks mail, calendar, Slack and Jira, and messages you only when something needs you (or always, your call). Morning brief and end-of-day too.
🟠
Tray app
An orange dot keeps the session running in the background, restarts it if it dies, starts at login, and continues the same conversation. One instance, one session.
🔒
Folder guard
Allow everything (no prompts, default) or ask first; either way a hook blocks any file or shell command outside the folders you allow, and keys and credentials are never touched. OS sandbox on macOS and Linux.
🔌
Your services
Gmail, Calendar, Drive, Slack via claude.ai connectors, Jira via Atlassian. Authorize each one from the installer's Done page, one click apiece.

Six steps, five minutes

[4]

[6]

What is in your folder, the Telegram status, services to authorize, a health check. Start the tray app, message the bot.

Outside the folder: one line in ~/.claude.json that marks it trusted, the Telegram plugin's own state dir, and the scheduled jobs (Task Scheduler, launchd or cron). Uninstall on the Done page removes all of it.

Questions

Does the bot need Claude Code open?

Yes: the bot lives inside a running Claude Code session. That is what the tray app keeps alive (and restarts). Messages you send while it is off wait in Telegram for up to a day and arrive when it is back. Scheduled pushes (brief, radar) do not need a session.

Why "allow everything"? Is that safe?

A background session cannot stop to ask you; every prompt would go to your phone. So inside the folder it does not ask. It still confirms in chat before sending mail, posting or creating events (that is in its rules), and the folder guard blocks file and shell access outside the folders you allowed, plus keys and credentials anywhere. Pick "Ask me first" if you prefer prompts.

Windows: is there a sandbox?

Claude Code's OS sandbox exists on macOS and Linux only; the installer enables it there. On Windows the folder guard hook is the fence: it checks every file and shell command before it runs.

Gmail, Calendar, Slack: how do they connect?

They are claude.ai connectors (claude.ai → Settings → Connectors). Each needs a one-time authorization on your machine; the Done page has an [ authorize ] button per service that opens the approval page. Jira/Confluence use the Atlassian MCP server with its own OAuth.

Can I run more than one assistant?

One tray per folder and one phone session per machine (two sessions would fight over the same bot). Several folders with different bots work; start them one at a time.

How do I remove it?

Done page → Uninstall: stops the sessions and removes the scheduled jobs, login autostart, plugin scope, trust entry and launchers. "Purge" also deletes .pa and .claude. Or pa-installer uninstall <folder> [--purge].
